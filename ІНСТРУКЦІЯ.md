# Віш-ліст: як запустити

Сайт складається з трьох файлів: `index.html`, `config.js` і `firestore.rules` (останній потрібен лише один раз, для Firebase). Хостинг потрібен будь-який, який віддає звичайні сторінки (Netlify, GitHub Pages, ваш хостинг із cPanel).

## 1. Свої дані

Відкрийте `config.js` у Блокноті й змініть ім'я, дату, повідомлення та список подарунків. Для кожного подарунка:

- `id`: унікальний, латиницею, цифри і дефіс, без пробілів (наприклад `lego-city`). Не змінюйте id після того, як гості почали бронювати, бо бронь прив'язана до нього.
- `title`: назва. `price`, `link`, `note`: за бажанням, можна залишити `""`.

Також у `config.js` є два необов'язкові поля:

- `dressCode`: напис про дрес-код (з'являється бежевою пігулкою в шапці). Щоб прибрати, залиште `""`.
- `photo`: фото іменинника. Покладіть файл у ту саму папку, що й `index.html`, і впишіть його назву, наприклад `photo: "photo.jpg"`. Найкраще квадратне фото, не більше 1 МБ (зменшіть його перед завантаженням). Воно показується в колі. Якщо файлу немає, фото просто не з'явиться.

Щоб додати подарунок, скопіюйте рядок `{ id: ..., },` і змініть. Не забудьте кому між рядками.

## 2. Перегляд без Firebase

Відкрийте `index.html` у браузері двічі клацнувши. Працює демо-режим: бронь видно лише на вашому комп'ютері. Так можна перевірити вигляд і текст.

## 3. Firebase, щоб бронь бачили всі (безкоштовно, ~10 хвилин)

1. Зайдіть на https://console.firebase.google.com під своїм акаунтом Google і натисніть «Create a project». Google Analytics можна вимкнути.
2. У меню зліва: **Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save**. Це дає кожному гостю анонімний вхід (гості нічого не вводять і ніде не реєструються).
3. **Build → Firestore Database → Create database**. Режим оберіть **production**, регіон будь-який європейський (наприклад `eur3`).
4. У Firestore відкрийте вкладку **Rules**, видаліть усе, що там є, вставте вміст файлу `firestore.rules` і натисніть **Publish**. Ці правила не дозволяють забронювати вже зайнятий подарунок і не дають скасувати чужу бронь.
5. Щоб отримати блок налаштувань: головна сторінка проєкту → іконка `</>` (Web app) → дайте назву → **Register app**. З'явиться код `const firebaseConfig = { ... }`. Скопіюйте з нього чотири рядки (`apiKey`, `authDomain`, `projectId`, `appId`) у `config.js`:

```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  appId: "..."
};
```

6. Якщо ваш сайт буде на власному домені: **Authentication → Settings → Authorized domains → Add domain**, додайте свій домен (наприклад `wishlist.example.com`). Без цього вхід гостей не спрацює.

## 4. Завантаження на хостинг

Завантажте `index.html`, `config.js` і (якщо є) фото в одну папку на хостингу. Файл `firestore.rules` завантажувати не потрібно. Відкрийте адресу сайту на телефоні й комп'ютері та спробуйте забронювати щось в одному браузері: в іншому цей подарунок має стати сірим.

Після перевірки зніміть тестові броні кнопкою «Скасувати бронь». Якщо не вийшло, видаліть записи в Firestore Database → колекція `reservations`.

## Що варто знати

- Гості не бачать, хто саме забронював, лише що подарунок зайнятий. Ви можете побачити технічний ідентифікатор у Firestore, але не імена.
- Скасувати бронь може тільки той браузер, у якому її зробили. Якщо гість зайшов з іншого пристрою або очистив дані браузера, скасувати не вийде. Тоді зніміть бронь самі: Firestore Database → колекція `reservations` → видаліть потрібний документ.
- Безкоштовного ліміту Firebase (Spark) для такого списку вистачає з великим запасом.
